Integration wireframe · Zopping × Shopify

KOW split-order flow

A customer buys 4 items on the KOW website. Zopping knows stock at every store and warehouse, so it returns a split-cart plan. KOW then places one order per fulfilment location. Each order is tracked, returned and refunded on its own.

Who does what

KOW website

Customer-facing store. Shows the split at checkout, places the orders, and shows them under My Account.

Shopify

KOW's commerce platform. Holds the cart and payment, and lists each split order as a separate Shopify order.

Zopping

Store-wise inventory and the split-cart logic. Receives the orders and runs fulfilment, tracking and returns per order.

Order placement flow

Step 1

Customer checks out

Cart has 4 items (A, B, C, D) and a delivery pincode.

Step 2

Split-cart request

KOW sends cart + pincode. Zopping checks stock at each location.

POST /cart/split
Step 3

Split plan returned

3 shipments, each with source location and delivery ETA.

Step 4

3 orders placed

One payment. KOW calls order placement 3 times, one per shipment.

POST /order × 3
Step 5

Order-level lifecycle

3 orders in Zopping and Shopify. Tracking, cancel, return and refund per order.

Cart display: split or as-is

Zopping returns an ETA for each shipment. If ETAs differ, the KOW cart groups items by arrival date. If every shipment has the same ETA, the cart stays as it is today, and we only tell the customer the order comes in 2 shipments.

Display rule

  1. KOW calls Zopping split-cart when pincode is known (cart drawer or checkout).
  2. ETAs differ → group cart items under Shipment 1, 2… with arrival date per group.
  3. All ETAs same → keep the cart as it is now. Show one "Arrives by" date and "Ships in N packages".
  4. On order placed, always show "Comes in N shipments" with each order ID and date.
  5. Only 1 shipment → no split message at all.
same_eta = all(s.eta == shipments[0].eta for s in shipments)

Order-level rules

Tracking

Each order has its own AWB and status. Group status is derived: Partially delivered until all 3 are delivered.

Cancel & return

Done per order. Cancelling Delhi order does not touch HSR or Chennai orders.

Refund

One payment, partial refunds per order back to the original payment on Shopify.
